# Python Practice

Standalone programming exercises in Python 3. The scripts use the standard library and read their own input from standard input.

## Run an example

From this project's directory in PowerShell, run the rolling-hash exercise on a palindrome.

~~~powershell
'racecar' | python .\practice\palindrome_extension.py
~~~

Expected output is `0`. The script compares prefixes and suffixes with their reversals to find the shorter extension needed to form a palindrome.

The `practice/` directory also includes graph traversal, dynamic programming, and numeric exercises. Each script has its own input format.
